# Gunline assets

All models and textures in this folder are **CC0 1.0 (public domain)** by
[Kenney](https://kenney.nl). Commercial use is permitted and attribution is not
required; the credit below is courtesy.

| File | Pack | Source |
|---|---|---|
| `character-a.glb`, `texture-*.png` | Blocky Characters 2.0 | https://kenney.nl/assets/blocky-characters |
| `blaster-*.glb` | Blaster Kit 2.1 | https://kenney.nl/assets/blaster-kit |

`character-a.glb` carries 27 baked animations and has no skinned mesh: the rig
animates node transforms, which is why a clone of it costs almost nothing and
forty of them can share the frame.

The six `texture-*.png` files are alternate colourways for that same model. The
UV layout is identical across the pack, so swapping the material map is the
whole of what makes one enemy type look different from another.
